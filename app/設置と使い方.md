# 潜水現場記録 設置と使い方

## このフォルダの中身

| ファイル | 役割 |
|---|---|
| index.html | アプリ本体（画面・計算・保存がすべて入っています） |
| sw.js | 電波がない場所でも開けるようにする仕組み |
| manifest.webmanifest / icon-*.png / apple-touch-icon.png | ホーム画面に置いたときの名前とアイコン |
| 潜水表_NAUI2022.json | 今アプリに入っている潜水表（NAUI 2022年版カードの写真から書き起こし）。差し替えるときの見本 |

## GitHub Pages に置く

1. このリポジトリ（diveops）を GitHub に置く。
2. Settings → Pages → Branch を main、フォルダを /docs にして保存する。
3. 以後は docs/ を更新して main に入れると、数分で公開版が新しくなる。
4. 表示されるURL（https://（アカウント名）.github.io/diveops/）を現場用スマホで開く。

## 現場用スマホに入れる

- iPhone：Safariで開く → 共有ボタン → 「ホーム画面に追加」
- Android：Chromeで開く → 右上のメニュー → 「ホーム画面に追加」（または「アプリをインストール」）

**必ずホーム画面のアイコンから開いて使ってください。** iPhone では、Safari で開いたときとホーム画面から開いたときで記録の置き場所が別になり、Safari で入れた記録はホーム画面のアプリから見えません。また Safari のタブで使うと、しばらく開かないと記録が消されることがあります。

一度開いておけば、電波のない場所でも起動します。記録はスマホの中に保存され、外部のサーバーには送られません。新しい版が出ると、画面の下に「新しい版があります［更新する］」と出ます。記録中でなければ押してください。

## 運用の決まり

- **1つの事案は1台のスマホで記録する。** 2台で同じ事案を記録すると、事案が2件に分かれ、2台目の反復潜水が1本目として計算されてしまいます（甘い判定になります）。
- 事案が終わったら、その日のうちに署へ送る。送っていない事案はホームに「未送信」と出ます。
- 月に1回、設定 →「控えを作る」で記録をファイルに残し、署のパソコンに保管する。

## 使い方の流れ

1. 設定 → 隊員を登録（Excelの隊員マスタから「職員番号,氏名」を貼り付けて、まとめて登録できます）。見本の隊員と事案は「見本を消す」で消してから使い始めます。
2. ホーム → 新しい事案を始める（区分・地点・指揮者・監視員・潜水員）
3. 潜水員ボードで「潜降」→ 予定の水深と開始圧 → 上限の時間を確認して記録
4. 潜水中は経過時間と残り時間が出ます。残り5分で枠付き、上限を超えると白黒反転で「上限超過」と出ます。
5. 浮上の合図で「浮上開始」→ 水面に着いたら「水面に着いた」→ 最大水深・終了圧・体調異常を入れて記録。潜水時間は潜降から浮上開始までで自動で入ります。減圧停止が必要な判定になったときは、実際に5mで止まった時間も入れます。
6. 休息中は、次も同じ水深に潜った場合の上限が自動で更新されます。
7. 記録を直すときは、潜水員の名前 → 直したい本 → 理由を入れて保存。前の値と直した日時は残り、CSVの「修正記録」にも出ます。削除した記録も「状態=削除」としてCSVに出ます。
8. 「終了の手続きへ」→「事案を終了する」→「メールで送る」→ 署のアドレスへ送信。
9. 署のパソコンでCSVを保存し、潜水管理台帳の［アプリのCSVを取り込む］で取り込む。直した記録・削除した記録は、記録IDで照合して台帳も直ります。報告書シートで事案IDを選んで［報告書をPDF］。マクロの組み込み方は台帳の「使い方」シートを見てください。

CSVは、Excelでダブルクリックして開いて上書き保存しないでください（文字コードが変わって取り込めなくなります）。メールで届いた元のファイルを取り込みます。

## 記録・経歴簿（Excel出力）

1. 設定 → 隊員の名前を押す → 職員番号が自分のものか確かめてから、所属・在籍状態と、資格・研修（名称はボタンで選ぶ・取得日・有効期限・期別）を入れる。本人が自分の分を入れてかまいません。入れた資格は「未確認」で、担当者が免許証・修了証の写しで確かめ、担当者名を入れて「確かめた」を押すと確認済みになります。
2. アプリを使う前の記録があれば、設定 →「過去の記録を取り込む」で、台帳の「CSV抽出」シートの［CSVで保存］で作ったCSVを選ぶ。
3. ホーム →「記録・経歴簿（Excel出力）」→ 期間と隊員を選ぶ → 画面で本数・最大水深・資格を確かめる。
4. 「Excelで出力」→ メールで送るかファイルに保存。シートは「隊員一覧」「経歴簿_氏名」（1人1シート。累計と期間の本数）「潜水記録（参照用）」「資格・研修」。
5. 台帳に入れるときは「台帳用CSV」を出して、台帳の［アプリのCSVを取り込む］で取り込む（Excelの「潜水記録（参照用）」シートを台帳に貼り付けないでください。列の並びが違い、台帳の数式が壊れます）。

- 潜水士免許の登録がない（期限切れを含む）隊員を潜水員に選ぶと「× 潜水士免許の登録がありません」と出ます（記録は止めません）。
- 出力するファイルには氏名と体調異常などの記録が入ります。送る先に注意し、必要なら「体調異常・備考・資格の期別番号を出力しない」にしてください。
- 取り込んだ事案は「取り込み」の印が付き、アプリでは直せません（正本は台帳）。ホームの「これまでの事案」は直近10件で、残りは「すべての事案を見る」から。

- Excelの部品は、一度電波のある所でアプリを開けば、その後は電波がなくても使えます。
- アプリに入っているのは、このスマホで記録した潜水と、取り込んだ記録だけです。2台以上で記録した分は入りません。
- 記録の正本は署に保存してください（月1回、全員分をExcelで出力して署のフォルダに保存する、など）。スマホの故障や紛失で、アプリの中の記録は消えます。
- 異動・退職した隊員は、在籍状態を変えます（削除すると経歴簿から名前が消えるため、記録のある隊員は削除できません）。

## 潜水表の差し替え

潜水管理台帳の「潜水表」シートで直して［アプリ用に書き出す］→ できた .json をスマホへメールで送る → アプリの ホーム → 潜水表 → 「潜水表ファイルを読み込む」。読み込み時に自動で点検し（表の数値に加え、水面休息の最短時間や1本目に戻る時間などの決まりごとも確かめます）、変わる箇所の一覧を確認してから切り替えます。進行中・過去の事案は、始めたときの表のまま計算します。

## 知っておいてほしいこと

- 入っている潜水表は、NAUI 2022年版カード（日本語版）から書き起こし、2026年10月24日に隊内2名で照合済みです。
- アプリの判定は計算の目安です。ダイブコンピュータと指揮者の判断を優先してください。潜水表で上限を決められない場面（休息10分未満など）では、空気の時間で代わりに埋めず「判断できません」と出します。
- 「低水温・重作業のため1段階厳しくする」を選ぶと、潜る前の上限も、グループを1つ重くしても減圧停止にならず、次の潜水も計算できる時間まで短くなります（例：18mの1本目は50分→45分。6mは表のグループがKで終わるため461分→330分）。
- 必要な減圧停止より短く止まったと記録すると、その人の次の潜水は計算しません（24時間は潜らない扱い）。
- 浮上から14時間は、重激な業務を避けてください（高圧則 第18条）。潜水員の詳細に時刻が出ます。
- 作業の記録は5年間保存します（高圧則 第20条の2）。台帳とCSVの保管場所を隊で決めておいてください。
- 記録はスマホの中（IndexedDB）だけにあります。ブラウザの「履歴とWebサイトデータを消去」をすると記録も消えます。
