# 潜水現場記録（初版）設置と使い方

## このフォルダの中身

| ファイル | 役割 |
|---|---|
| index.html | アプリ本体（画面・計算・保存がすべて入っています） |
| sw.js | 電波がない場所でも開けるようにする仕組み |
| manifest.webmanifest / icon-*.png / apple-touch-icon.png | ホーム画面に置いたときの名前とアイコン |
| 潜水表_NAUI2022.json | 今アプリに入っている潜水表（NAUI 2022年版カードの写真から書き起こし）。差し替えるときの見本 |

## GitHub Pages に置く

1. このリポジトリ（diveops）を GitHub に置く。
2. Settings → Pages → Branch を main、フォルダを /docs にして保存する。
3. 以後は docs/ を更新して main に入れると、数分で公開版が新しくなる。
4. 表示されるURL（https://（アカウント名）.github.io/diveops/）を現場用スマホで開く。

## 現場用スマホに入れる

- iPhone：Safariで開く → 共有ボタン → 「ホーム画面に追加」
- Android：Chromeで開く → 右上のメニュー → 「ホーム画面に追加」（または「アプリをインストール」）

一度開いておけば、電波のない場所でも起動します。記録はスマホの中に保存され、外部のサーバーには送られません。

## 使い方の流れ

1. 設定 → 隊員を登録（Excelの隊員マスタから「職員番号,氏名」を貼り付けて、まとめて登録できます）
2. ホーム → 新しい事案を始める（区分・地点・指揮者・潜水員）
3. 潜水員ボードで「潜降」→ 予定の水深と開始圧 → 上限の時間を確認して記録
4. 「浮上」→ 最大水深・潜水時間・終了圧 → 判定を確認して記録
5. 休息中は、次も同じ水深に潜った場合の上限が自動で更新されます
6. 終了して書き出す → 「メールなどで送る」→ 署のアドレスへ送信
7. 署のパソコンでCSVを保存し、潜水管理台帳（第2版）の［アプリのCSVを取り込む］で取り込む。報告書シートで事案IDを選んで［報告書をPDF］

## 潜水表の差し替え

潜水管理台帳の「潜水表」シートで直して［アプリ用に書き出す］→ できた .json をスマホへメールで送る → アプリの ホーム → 潜水表 → 「潜水表ファイルを読み込む」。読み込み時に自動で点検し、変わる箇所の一覧を確認してから切り替えます。進行中の事案は、始めたときの表のまま計算します。

## 知っておいてほしいこと

- 入っている潜水表は、NAUI 2022年版カード（日本語版）から書き起こし、2026年10月24日に隊内2名で照合済みです。
- アプリの判定は計算の目安です。ダイブコンピュータと指揮者の判断を優先してください。
- 記録はスマホの中だけにあります。月に1回程度、設定 →「控えを作る」でファイルを残してください。
- ブラウザの「履歴とWebサイトデータを消去」をすると記録も消えます。
