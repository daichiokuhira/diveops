# 潜水現場記録 設置と使い方（v0.5.0・共有版）

記録は、隊の全員で共有します（Cloudflare に置いた共有の保存先。市の許可を得て使っています）。どの端末で入れた記録も、電波があれば数秒で全員の端末に届きます。電波がない間は端末に貯めておき、電波が戻ると自動で送ります。

## このフォルダの中身

| ファイル | 役割 |
|---|---|
| index.html | アプリ本体（画面・計算・端末への保存・共有がすべて入っています） |
| sw.js | 電波がない場所でも開けるようにする仕組み |
| exceljs.min.js | Excel出力の部品 |
| manifest.webmanifest / icon-*.png / apple-touch-icon.png | ホーム画面に置いたときの名前とアイコン |
| 潜水表_NAUI2022.json | 今アプリに入っている潜水表。差し替えるときの見本 |

共有の保存先（API）のプログラムは、リポジトリの server/ にあります。公開の手順は「共有の保存先を公開する（管理者）」を見てください。

## スマホに入れて、ログインする

- iPhone：Safariで開く → 共有ボタン → 「ホーム画面に追加」
- Android：Chromeで開く → 右上のメニュー → 「ホーム画面に追加」（または「アプリをインストール」）

**必ずホーム画面のアイコンから開いて使ってください。** iPhone では、Safari のタブとホーム画面のアプリで保存場所が別になります。

1. アイコンから開くと、ログイン画面が出ます。
2. **自分の職員番号**と、**隊のパスコード**を入れて「ログイン」。パスコードは隊長から聞きます（ほかの人に教えない）。名簿に無い人は、隊長に登録を頼みます。
3. ログインは使っている間は切れません（使わないまま30日たつと、ログインし直しになります）。

ログインし直しが必要になったとき（期限切れ・パスコードの変更・在籍の変更）も、画面は替わらず記録を続けられます。画面の上に「共有が止まっています［ログインし直す］」と出るので、電波のある所でログインし直してください。まだ送れていない記録は、そのとき送ります。

## 画面の右上の表示

| 表示 | 意味 |
|---|---|
| ✓ 共有済 | すべて送り、ほかの端末の記録も受け取っています |
| 送信中 | 送っているところです |
| 未送信 | 電波がないなどで、まだ送れていない記録があります。電波が戻ると自動で送ります |
| 電波なし | 電波がありません（送る記録はありません） |
| 共有停止 | ログインし直しが必要です（記録は続けられます） |

設定の「ログイン」には、詳しい状態と「今すぐ共有」があります。

## 運用の決まり

- **1人の潜水員は、1台の端末で記録する。** 電波があれば、1つの事案を複数の端末で記録してかまいません（例：隊長Aの端末で1人目、隊長Bの端末で2人目）。
- **電波がない現場では、1つの事案は1台で記録する。** 電波がない間、ほかの端末の記録は届きません。届いていない潜水があると、反復潜水が1本目として計算され、甘い判定になります。ボードに「ほかの端末の記録が届いていないかもしれません」と出たら、特に注意してください。
- 現場用スマホを別の人が使うときは、設定 →「使う人を替える」。ログイン画面に戻るだけで、記録は端末に残ります（電波がないときは替えられません）。
- 私物のスマホで使い終わったときは、設定 →「私物のスマホで使い終わったとき」→「この端末から記録を消してログアウト」（送れていない記録や進行中の事案があるときは消せません）。
- 端末の日時は自動に設定しておいてください（大きくずれた端末の変更は受け付けません）。

## 使い方の流れ

1. 隊長：設定 → 隊員を登録（Excelの隊員マスタから「職員番号,氏名」を貼り付けて、まとめて登録できます）。
2. ホーム → 新しい事案を始める（区分・地点・指揮者・監視員・潜水員）。
3. 潜水員ボードで「潜降」→ 予定の水深と開始圧 → 上限の時間を確認して記録。
4. 潜水中は経過時間と残り時間が出ます。残り5分で枠付き、上限を超えると白黒反転で「上限超過」と出ます。
5. 浮上の合図で「浮上開始」→ 水面に着いたら「水面に着いた」→ 最大水深・安全停止・終了圧・体調異常を入れて記録。減圧停止が必要な判定になったときは、実際に5mで止まった時間も入れます。
6. 休息中は、次も同じ水深に潜った場合の上限が自動で更新されます。
7. 記録を直すときは、潜水員の名前 → 直したい本 → 理由を入れて保存。前の値と直した日時は残ります。
8. 「終了の手続きへ」→「事案を終了する」。**メールで送る必要はありません**（「この事案の記録は共有済みです」と出れば完了）。
9. 署のパソコン：ブラウザでアプリを開いてログイン → 「記録・経歴簿」→ 期間と隊員を選ぶ →「台帳用CSV」→ 潜水管理台帳の［アプリのCSVを取り込む］で取り込む。報告書シートで事案IDを選んで［報告書をPDF］。

## 資格・研修

1. 各自：設定 → 自分の名前 → 画面上の**職員番号が自分のものか確かめて**から、資格・研修（名称はボタンで選ぶ・取得日・有効期限・期別）を入れる。ほかの人の欄には入れられません。
2. 入れた資格は「未確認」です。**隊長**が免許証・修了証の写しで確かめて「証の写しで確かめた」を押すと、確認済みになります（確かめた隊長の名前が残ります）。
3. 潜水士免許の登録がない人を潜水員に選ぶと「× 潜水士免許の登録がありません」、未確認なら「免許未確認」と出ます（記録は止めません）。

## 役割

| 役割 | できること |
|---|---|
| 隊員 | 事案・潜水の記録、自分の資格・研修の入力、記録・経歴簿の閲覧とExcel出力 |
| 隊長 | 上に加えて、隊員の追加・氏名・所属・在籍の変更、資格の確認、過去の記録の取り込み |
| 管理者 | 上に加えて、隊長の指名（隊員の画面の「隊長にする」）、パスコードの管理 |

異動・退職にした隊員は、潜水員の候補から外れ、ログインもできなくなります。記録は残ります。

## 記録・経歴簿（Excel出力）

ホーム →「記録・経歴簿（Excel出力）」→ 期間と隊員を選ぶ →「Excel」または「台帳用CSV」。共有の記録すべて（どの端末で記録したものも）が入ります。

- Excel のシート：「隊員一覧」「経歴簿_氏名」（1人1シート）「潜水記録（参照用）」「資格・研修」。
- 台帳に入れるときは「台帳用CSV」を取り込みます（Excelのシートを台帳に貼らない）。
- ファイルには氏名と体調異常が入ります。送る先に注意し、必要なら「Excelに体調異常・備考・期別番号を出さない」にしてください。
- アプリを使う前の記録は、隊長が設定 →「過去の記録を取り込む」で、台帳の「CSV抽出」で保存したCSVを取り込めます。

## 潜水表の差し替え

潜水管理台帳の「潜水表」シートで直して［アプリ用に書き出す］→ できた .json をスマホへ送る → アプリの ホーム → 潜水表 →「潜水表ファイルを読み込む」。読み込み時に自動で点検し、変わる箇所の一覧を確認してから切り替えます。潜水表は端末ごとの設定で、進行中・過去の事案は始めたときの表のまま計算します。

## 共有の保存先を公開する（管理者）

1. このMacで `npx wrangler login`（ブラウザで Cloudflare にログインして許可）。
2. `cd server && npx wrangler d1 create diveops` → 表示された database_id を wrangler.toml に書く → `npx wrangler d1 execute diveops --remote --file schema.sql`。
3. `npx wrangler secret put TEAM_PASSCODE`（隊のパスコードを本人が入力。12文字以上の推測しにくいもの）、`openssl rand -hex 32 | npx wrangler secret put SECRET_KEY`（長い乱数）、`npx wrangler secret put ADMIN_IDS`（管理者の職員番号。複数はカンマ区切り）。
4. `npx wrangler deploy`（初回だけ workers.dev の名前を登録する）→ 表示された URL を app/config.json の apiBase に書き、`npm run build:app` で作り直して push する。

今の公開先は `https://diveops-api.miyako-dive.workers.dev`（2026-10-25 公開）。server/ を直したら `cd server && npx wrangler deploy` で入れ直します。

**パスコードを変えるとき**は、進行中の事案がないときに `npx wrangler secret put TEAM_PASSCODE` で入れ直し、隊員に新しいパスコードを伝えます（全員がログインし直しになります。記録は消えません）。漏れた疑いがあるときは、すぐに変えてください。

## 知っておいてほしいこと

- 入っている潜水表は、NAUI 2022年版カード（日本語版）から書き起こし、2026年10月24日に隊内2名で照合済みです。
- アプリの判定は計算の目安です。ダイブコンピュータと指揮者の判断を優先してください。潜水表で上限を決められない場面では、空気の時間で代わりに埋めず「判断できません」と出します。
- 「低水温・重作業のため1段階厳しくする」を選ぶと、潜る前の上限も短くなります（例：18mの1本目は50分→45分）。
- 必要な減圧停止より短く止まったと記録すると、その人の次の潜水は計算しません（24時間は潜らない扱い）。
- 浮上から14時間は、重激な業務を避けてください（高圧則 第18条）。
- 作業の記録は5年間保存します（高圧則 第20条の2）。正本は署の台帳（取り込んだ記録とPDF）として保存してください。
- 記録の変更は、誰が・いつ変えたかが共有の保存先に残ります。
